产品概述
Galbot SDK 是专为 Galbot 系列机器人平台提供的统一二次开发工具包。通过封装底层硬件通信与算法细节，提供原子化控制与感知能力，以及可选的业务级能力。适用于工业与零售集成、学术研究等场景，帮助开发者通过简洁的 API 快速实现运动控制、感知交互与自主导航。
核心功能
​
Galbot SDK 采用分层解耦设计，将机器人能力划分为三大核心层次，覆盖从底层控制到高层业务的全场景开发需求。
1. 基础能力
​
提供硬件直接控制与原始数据访问能力，实现对机器人的操控与传感器数据获取。
运动控制
：支持关节空间位置/轨迹控制、末端笛卡尔空间位姿/轨迹控制，以及底盘的速度开环控制与紧急停止。
传感器读取
：提供彩色/深度视觉流、雷达点云、IMU 惯性数据、力传感器及超声波等全方位环境感知数据。
人机交互
：包含麦克风流采集、音频播放控制、RGB 指示灯效果设置。
系统与安全
：支持电源/日志系统监控、软件急停机制、碰撞保护参数配置及实时资源销毁管理。
2. 高级能力
​
提供内置算法服务访问能力，支持自定义算法推理与执行。开发者可根据需求使用内置算法服务，或自行设计算法。
规划与控制接口
实时控制：开放高频实时关节/末端指令接口，支持自定义闭环控制算法及 VLA、RL 等推理执行。
正逆运动学：提供正向运动学与逆向运动学计算接口，支持约束优化。
运动规划：支持单链与全身多链、单路点轨迹与多路点连续轨迹生成，并具备自碰撞与环境碰撞检测功能。
环境管理：支持动态添加/删除障碍物，以及附加末端工具与目标物体。
导航接口
自主导航：具备 SLAM 建图定位、全局/局部路径规划及动态避障能力，支持导航任务的精准下发与状态监控。
3. 业务能力
​
提供场景化业务逻辑封装，包含料箱搬运、SPS 分拣等业务场景能力。用户可根据实际场景进行参数配置和流程修改，快速实现特定业务功能。该部分能力需联系商务解锁。
SPS 分拣模块
：针对分拣场景的自动化拾取与放置逻辑。
料箱搬运模块
：料箱识别、堆叠及搬运流程的快速实现。
更多业务模块持续开发中。
应用场景
​
Galbot SDK 可根据用户实际需求，应用于包括但不限于以下场景：
工业场景：物料搬运与分拣、智能仓储管理
零售场景：商品分拣与配送
服务场景：迎宾导览服务
研究场景：机器人算法研究、人机交互实验
服务与支持
​
Galbot SDK 提供以下服务与支持：
技术文档：API 参考、开发示例与最佳实践
技术支持：技术咨询与问题解答群
定制服务：根据客户需求，提供 SDK 使用培训与开发指导，提供业务能力模块授权，细节请联系商务
