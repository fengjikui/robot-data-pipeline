# 界面验收入口

由工作台 Python 服务提供此目录，不支持直接双击 `index.html`。

1. 空工作区打开后，不显示假数据或虚构指标。目录为空，主区域说明导入流程。
2. 点击“生成合成教学样例”，确认资产标记为教学用途；不会自动加载或下载外部数据。
3. 点击“运行质量检查”，切换到运行记录；完成后可查看错误/警告、日志和结构化结果。
4. 通过检查后点击“导出 JSONL”，确认存在产物下载链接，并明确标注它不是 LeRobot 训练集。
5. 勾选“检查通过后自动导出”，检查与导出按顺序进行，遇错停止。
6. 使用中文、空格、引号和 HTML 字符作为资产名与标签，界面按文字呈现。
7. 用任务名、标签及来源筛选；清空筛选能恢复资产列表。
8. 编辑目标任务、本体和策略，刷新后配置仍保存；来源本体不被替换成目标本体。
9. 测试网络中断、错误路径、未支持格式，页面显示可读错误且表单内容保留。
10. 760 px 以下侧栏改为横向目录；阶段横向可滚动；键盘 Tab 可达操作，左右键切换详情页签。

界面没有接入真机、训练、仿真与部署，后续阶段在流程图中清楚说明待接入条件。正文数据均使用 DOM `textContent`，无外部 CDN、字体或网络请求。
