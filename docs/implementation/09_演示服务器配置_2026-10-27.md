# 搬箱管线演示：服务器配置

> 状态：当前已按用户要求暂缓服务器训练与仿真方向，优先开发本地工作台界面。本文保留为后续备查，不代表当前需要采购服务器。

日期：2026-10-27。用途：NVIDIA Arena G1搬箱任务的环境验证、公开策略闭环推理、小规模GR00T N1.6训练及训练后测试。本页是工程配置建议，不是已经测得的显存需求或训练效果保证。

## 建议先租的配置

| 项目 | 建议 |
| --- | --- |
| GPU | 先用1×NVIDIA L40S 48GB，L40 48GB可作为候选；预算充足可用2张，将仿真和策略推理分卡运行 |
| CPU | 至少16 vCPU，推荐32 |
| 主存 | 推荐128GB；需同时看GPU实例实际分配的CPU和内存 |
| 磁盘 | 推荐500GB可用SSD空间，环境和缓存不能只放在很小的系统盘 |
| 系统 | Ubuntu24.04，x86_64；22.04也在所选Isaac Sim文档支持范围内 |
| 访问 | SSH，可安装系统依赖，能下载GitHub、Hugging Face和NVIDIA仿真资源 |
| 图形能力 | 必须向实例暴露Vulkan/RTX离屏渲染能力，包含所需的NVIDIA图形库 |

先按小时租用并完成环境预检，再决定续租。此处未核实AutoDL实时库存或价格，不建议直接按月采购或购买实体服务器。

L40S的48GB显存、RT Core与Tensor Core见[NVIDIA规格](https://www.nvidia.com/en-sg/data-center/l40s/)。CPU、128GB主存及磁盘预留是本项目对训练、仿真、资源缓存的工程建议，并非官方统一最低值。

## 租前最重要的兼容性确认

将下面的问题直接发给云平台客服或查看实例说明：

> 这台Linux GPU实例是否支持NVIDIA Isaac Sim 6.0系列的Vulkan/RTX离屏渲染和相机输出？容器内是否包含对应的NVIDIA图形驱动库，而非仅CUDA计算库？宿主NVIDIA驱动是什么版本？是否能用SSH安装依赖并运行原生uv环境？

所选Arena固定版本要求Isaac Sim6.0.1、Isaac Lab3.0.0，支持原生uv安装及Docker。不能把另一版AutoData/Isaac Sim6.1的软件与驱动要求直接混进这份配方。[Arena安装说明](https://github.com/isaac-sim/IsaacLab-Arena/blob/38b200cdb4b506ee8329e89480c6479cae5bc2dc/docs/pages/quickstart/installation.rst)

对应的Isaac Sim6.0文档列出的Linux测试驱动为580.95.05。其他驱动要按具体版本核验，不能简单以CUDA版本代替图形兼容性检查。`nvidia-smi`正常不能单独证明Vulkan渲染可用。容器内通常也不能替云平台升级宿主内核驱动。[Isaac Sim6.0系统要求](https://docs.isaacsim.omniverse.nvidia.com/6.0.0/installation/requirements.html)

这次一台机器兼顾训练和渲染，不选择A100/H100：上述文档明确不支持没有RT Core的GPU用于Isaac Sim。已有昇腾资源可在后续另评估训练软件适配，但不能替代本条Isaac Sim的RTX图形执行环境。

## 单卡能够承诺的工作范围

1. 先检查驱动、图形、磁盘和资源下载，运行小规模离屏场景，确认相机输出。
2. 用公开的匹配检查点跑闭环推理基线，确认动作、环境和控制器接口。
3. 再连接本轮数据选择、处理和小规模训练，按实测显存减少batch/worker，训练与评估分时运行。
4. 对本轮训练的模型单独评价、保存录像及失败结果，不能将公开模型的视频充当本轮训练效果。

Arena官方完整训练示例采用8张至少48GB显存GPU，说明在8×L40S上约需4–8小时，并建议512GB或更多主存。文档允许按较少资源降低batch和worker，但单卡不能据此承诺相同训练时长或质量。先租单卡用于工程试跑，不等于复现完整配方。[固定训练说明](https://github.com/isaac-sim/IsaacLab-Arena/blob/38b200cdb4b506ee8329e89480c6479cae5bc2dc/docs/pages/example_workflows/locomanipulation/step_4_policy_training.rst)

单卡能否同时容纳当前场景与策略，要连上后实测。若预算允许，双48GB卡可将两者分开；两张卡的显存不应当作一块96GB统一显存。
