# 路径选择与三平台说明

版本：v0.1.2。数据目录使用操作系统的原生选择窗口，取代 v0.1.1 的网页目录浏览器。当前唯一的可填写路径是“数据目录”；任务、名称、标签仍是文本。工作区由启动参数指定，输出与日志路径由系统管理。

## 使用方法

1. 点击“导入本地目录”，再点击“选择文件夹…”。
2. 在当前电脑的系统窗口中找到数据目录，确认选择。
3. 路径填回表单后，核对来源、任务、本体和许可，再点击“复制并登记资产”。选择路径本身不会开始导入。

取消选择时保留原路径与表单内容。也可直接粘贴绝对路径。已填写路径会作为打开窗口的初始位置；若末尾目录尚不存在，从最近的已有父目录开始。

## 各平台实现

| 平台 | 系统选择器 | 运行条件 |
| --- | --- | --- |
| Windows | `System.Windows.Forms.FolderBrowserDialog` | Windows 自带 PowerShell，以 STA 模式运行；不要求执行 `.ps1`，不修改执行策略 |
| macOS | AppleScript `choose folder` 系统目录窗口 | 使用系统自带 `osascript`，不要求安装 Tk 或浏览器扩展 |
| Linux | 桌面提供的 Zenity 或 KDialog 目录窗口 | 需要图形桌面与对应组件；KDE 优先 KDialog，其他桌面优先 Zenity |

没有图形桌面的 Linux 服务器不能显示系统窗口，会提示手动粘贴路径。有桌面但缺组件时，可安装发行版提供的 `zenity` 或 `kdialog`。本版本不再提供网页仿制选择器。

选择器打开在**运行工作台服务的那台电脑**上。本工具目前只监听 `127.0.0.1`；不能把服务器上的系统窗口当成远程浏览器客户端的文件上传窗口。

## 异常与进程管理

- 一次只允许一个选择窗口，防止重复点击；窗口等待上限为五分钟。
- 超时或工作台关闭时，只停止本工作台创建的选择器辅助进程。
- 路径作为参数或子进程环境变量传递，不拼接为 shell 命令；支持中文、空格和括号。
- 返回路径继续经过导入器的本机路径与链接检查；选择文件夹不代表其内容通过质检。
- 请求使用现有的 Host、Origin 和会话令牌保护，其他网站无法调用本地接口弹窗。

## 实现与验收边界

- `robot_pipeline/workbench/native_picker.py`：平台原生窗口、取消、并发与进程生命周期。
- `POST /api/paths/pick`：显式点击后打开窗口；旧 `/api/paths/list` 已移除。
- `static/path-picker.js`：等待、取消、回填和错误提示。
- `tests/test_workbench_native_picker.py`：参数编码、中文路径、取消、超时、并发、接口保护及选择后导入。
- 干净 wheel 安装烟测：使用注入的选择结果验证“选择结果 → 导入 → 真实 worker 质检/导出”，不会在 CI 中自动点击系统窗口。
- 原生组件探测：Windows 实例化真实 `FolderBrowserDialog`；macOS 编译实际 AppleScript；Linux 验证无桌面提示。组件探测和接口测试不等于三平台 GUI 点选验收。

本版本具体测试环境、commit、安装包哈希及 GUI 验证范围见[原生选择器验收](../../evidence/implementation/native_picker_acceptance_2026-10-26.json)。v0.1.1 的自绘选择器验收保留在原证据文件中，不作为本版本原生窗口的证据。

升级后必须重启旧服务并刷新页面；只刷新网页不能加载新后端接口。
