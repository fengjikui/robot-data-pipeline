## Windows 发现的问题

[第一次原生 CI](https://github.com/fengjikui/robot-data-pipeline/actions/runs/40249899652)中，Windows Python 3.11、3.14 在隔离 wheel 测试的中文帮助输出处失败：`python -I` 忽略 UTF-8 环境变量，重定向输出使用 cp1252，触发 `UnicodeEncodeError`。

修复是在工作台 CLI 入口、argparse 输出前显式设置 UTF-8；保留 `-I` 的测试条件，并增加强制 cp1252 的真实子进程帮助与错误输出回归。没有跳过该隔离安装测试或放宽其成功条件。另避免测试为了构造样例而在 Windows 上打开 `CON` 设备名，保留各系统的保留名校验。

最终三系统 CI 的链接、commit 与每组结果见本页末尾的原生复验记录及对应 JSON。
