# 用户页面、阶段按钮与异常流程

2026-10-26方案更新：当前v0.1.2仅完成本地导入、结构质检、自有JSONL与记录等基础能力。后续总体方向以[整体方案与分期](10_整体方案与产品价值_2026-10-26.md)、[交互详细设计](11_交互逻辑与界面设计说明.md)及[开发验收映射](12_开发工作包与验收映射.md)为本轮补充；下文未实现功能仍为规划。

这是供后续设计与实现使用的交互说明，不是已经运行的界面。首期按单人、单机器人设计；阶段按钮为主，可选择自动串联。用户不需要理解后台进程名才能知道下一步能做什么。

## 工作台的共同结构

顶部始终显示当前项目、任务、目标机器人配置、运行模式（真机或仿真）、当前控制权和会话状态。来源机器人另在数据详情显示，不能用来源替换目标。真机/仿真使用不同连接模板；运行期间不允许悄悄切换连接目标。

左侧按工作过程组织：项目概览、设备与环境、采集、数据、训练、评估、部署、运行记录。首次打开只有创建项目和设备/数据来源入口；没有数据时不放假指标或演示回合。某厂家只有调研材料时，显示“资料已登记”，不显示“设备可用”。

每个阶段采用相同的阅读顺序：本次使用什么输入 → 前置检查 → 可以执行的操作 → 正在发生什么 → 结果及下一步。常用选项放在主区域，版本、命令预览与详细日志放在可展开区域。配置不能只存在于表单，要随作业保存快照。

## 关键页面与按钮

| 页面 | 用户首先看到什么 | 主要按钮 | 完成后得到什么 |
| --- | --- | --- | --- |
| 项目概览 | 任务、目标设备、有效数据量、最近作业、当前缺项 | 继续上次阶段、选择来源、配置流程 | 可追踪的当前项目与待办 |
| 设备与环境 | Host、机器人计算单元、相机、XR 与训练机的角色和连接状态 | 检测连接、准备环境、保存配置 | 设备检查报告与就绪项/人工待办 |
| 采集 | 实时图像、输入新鲜度、控制范围、回合状态、存储余量 | 启用遥操作、开始录制、结束并保存、标记结果、结束会话 | 原始回合与保存完成清单 |
| 数据资产库 | 已登记来源、实际持有范围、分类、源本体和用途条件 | 登记来源、读元数据、复制/引用目录、下载所选范围、按任务筛选 | 资产档案、来源快照与可复用训练视图 |
| 数据处理 | 回合列表、预览、质量结果、筛选视图、格式差异 | 运行检查、保留/排除、切段、预览映射、配置增强、转换并验收 | 数据视图、检查报告与训练输入 |
| 训练 | 兼容数据视图、模型模板、主要参数、执行位置与预算 | 检查训练输入、开始训练、请求停止、查看产物 | checkpoint、预处理、配置、日志和指标 |
| 评估 | 本体/场景/控制器是否匹配、评估方式和试验集合 | 检查环境、运行评估、查看回合、播放视频 | 指标、失败分类、全部回合结果和视频 |
| 部署 | 目标设备与模型契约差异、当前策略版本和控制权 | 检查兼容、生成包、传输、启用、停止、回退 | 部署包及设备端运行/验收记录 |
| 运行记录 | 所有作业的阶段、设备、输入输出、状态与原因 | 查看日志、打开结果、重试失败阶段、清理本次残留 | 可恢复的运行历史 |

增强不是强制通过的关卡。训练时图像增强直接配置在训练配方中；生成新数据的增强进入数据处理作业，并保留与母回合的关系。无需重复打包的数据允许直接建立训练视图。

外部数据整理者使用“来源/目录、元数据预览、少量分类、获取范围、归档与检查”向导。训练使用者从“任务、本体、配方、用途”进入库内选数，详情显示匹配理由、缺项、适配计划和验证证据。先在已启用的少量组合中筛选，待接入对象单独展示。完整字段和例子见 [外部数据资产库](07_外部数据资产库与使用流程.md)。

## 采集按钮的具体语义

| 按钮 | 可用条件 | 点击后做什么 | 何时算完成 |
| --- | --- | --- | --- |
| 检测连接 | 已有设备档案，无冲突检查任务 | 执行实际只读的网络、版本、传感器/状态探测 | 得到每项结果；无法读取的项目显示未知 |
| 准备环境 | 档案有效；明确列出本次所需服务 | 启动和检查无控制接管副作用的服务，展示现场操作 | 必须服务就绪，人工项单独等待 |
| 启用遥操作 | 控制范围、设备目标与退出方式已定义，现场条件满足 | 按厂商流程准备控制；待 XR/主从有效后启用跟随 | 控制状态和输入已核实；不是进程启动即完成 |
| 开始录制 | 有效会话、记录器可写、所需观察新鲜且无保存冲突 | 请求进入录制，建立回合标识 | 观察到记录状态及首批有效样本 |
| 结束并保存 | 正在录制 | 请求停止采样，等待后台写入收尾 | 文件清单和记录器完成状态一致；回合可读取 |
| 标记结果 | 当前回合可关联；可在保存后补充 | 标注成功、失败、中止或未知及原因 | 标注记录持久化；不改写原始传感器数据 |
| 结束会话 | 有会话；若在录制则先执行明示的保存/中止流程 | 退出跟随、释放本次控制资源、清理本次启动的服务 | 退出状态已核实，未完成保存单独报告 |

“结束录制”“结束遥操作”和“设备紧急停止”具有不同效果。网页的停止按钮只有在对应设备能力和链路验收后才可标注其真实效果；不能把正常进程退出命名为硬件急停。失联时界面显示状态未知，设备本地控制层按经验证的策略处理。

## 数据检查和转换页需要解释什么

检查结果按错误、警告、未知、人工结论展示，允许按回合定位和预览。每个问题给出受影响内容、可能后果和可执行恢复入口，例如“右腕相机缺 21 帧 → 排除此回合，或切去受影响时段后复查”。不能用一个总分掩盖动作语义未知。

转换前展示差异清单：来源/目标本体、输入输出字段、顺序、单位、参考系、时间处理、图像 key、目标格式版本、将丢弃的信息、需要的迁移步骤。用户可以先运行少量样本的预览和读取验收；有字段映射界面不表示任意向量均可映射为目标动作。

筛选和切段形成新视图，原始回合留存。重新检查、改标注、改变训练划分或配置增强都会生成新的配置/视图版本；下游历史产物仍可查看，但不再被显示为当前配置的最新结果。

## 训练与评估页需要让人看懂的差别

训练页先选择可兼容的配方，再显示该配方实际需要的参数。例如 ACT 展示观察配置、动作 chunk 与执行步数；Diffusion 展示观察窗口、预测窗口、执行步数等。数据划分、相机、特征和归一化属于训练输入条件，不能被藏成不可见的默认值。资源使用和停止条件在提交前可见，远端训练任务保存到可再次连接的位置。

模型参数差异参考固定训练配置；这里只定义界面应表达的信息，不承诺已经接入这两个训练器。[R15]

评估页必须显示三种不同产物标签：数据/动作回放、离线模型预测、闭环策略评估。闭环指标同时展示试验次数、成功规则、种子/场景范围、失败与中止，视频可跳到对应回合。没有匹配场景时，允许看回放，但不显示搬箱成功率。

部署页分开“生成包”“传输”和“启用”。包中必须带策略、预处理/反归一化、特征契约、控制接口要求和版本。支持状态依赖具体设备适配器；缺少机端运行时或退出协议时，按钮旁写明缺项，而不是给所有设备统一显示可启用。

## 可选自动串联怎样工作

默认仍逐阶段操作。用户可选择已完成的回合/数据视图，勾选“检查 → 筛选规则 → 可选处理 → 训练输入 → 训练 → 仿真评估”，先预览依赖、执行位置、输出和停止条件，再启动。采集中的开放回合不进入自动链路。

链路遇到必须人工判读的数据、控制现场条件、能力缺失、失败或状态未知即停在相应节点。相机恢复、目录出现或等待时间过去，不自动等同于该节点通过。重试只重跑受影响节点及依赖它的后续作业，不从头重复全部采集。默认串联终点是仿真评估；设备启用通过部署页明确执行。

## 异常与恢复清单

| 情形 | 应当显示什么 | 用户可以做什么 | 后台约束 |
| --- | --- | --- | --- |
| PC2/远端服务连不上 | 设备、阶段、最后成功通信时间与错误 | 检查连接后重试该设备 | 不重复启动未知状态的控制程序 |
| 有视频但帧不再更新 | 对应相机与最后新帧时间 | 结束/标记本回合，恢复相机后新建回合 | 按模板规则中止或标记异常，不把旧帧当新数据 |
| XR 追踪失效或网页断开 | XR 输入/会话失联、控制状态是否可确认 | 按现场流程恢复或结束会话 | 本地看护负责已验收的超时退出；浏览器不驱动实时保持 |
| 磁盘不足或录制写入失败 | 采样状态、写入失败文件、未完成回合 | 更换目录/释放本任务空间、保留异常证据 | 不把部分目录登记为成功回合 |
| 命令超时而真实状态未知 | 超时与最后状态，不推断成功/失败 | 重新读取状态、核对机端后恢复 | 不盲目重放 toggle 或控制启用命令 |
| 转换失败/训练不能读 | 具体字段、回合和读取错误 | 改映射/筛选，重新预览并运行 | 输出保留为失败产物，不覆盖原始数据 |
| 训练机失联 | 作业状态未知、最后日志/心跳 | 重新连接并查实际进程/输出 | 不直接再开同一训练，不把失联判为训练结束 |
| 修改设备、数据或参数 | 哪些下游结果与新配置不一致 | 保留旧结果、建立新作业 | 不混用不同配置的 checkpoint 与部署契约 |
| 本机资源压力升高 | 作业用量、系统负载/可用内存与可取得的热状态 | 降并发、分段或暂停本任务 | 不影响用户其他进程；无温度传感器时不编造温度 |

## 首轮交互验收

实现后，让操作者仅看工作台完成一次设备准备、录制保存、排除异常回合、训练和查看评估；记录是否需要额外终端、找不到下一步或把未知误解为成功。同时注入上述故障，确认用户能定位并恢复。当前这只是待执行的验收计划，尚无界面可用性实测结论。
