## 本地证据如何复核

`evidence/product_research/code_revisions.json` 记录本轮新增源码版本；`web_source_manifest.json` 记录页面 URL、核查日期与下载响应/抽取文本哈希。网页抽取时去除了脚本、样式和公开示例凭据，抽取文本不是原始 HTML 的逐字替代。网页没有 commit，不保证以后不变；报告中的结论限定在本次核查版本。

本轮新增源码与数据卡快照的文件哈希列在 `evidence/product_research/snapshot_manifest.json`。旧宇树/LeRobot 参考组合仍见 `evidence/source_revisions.json`。本轮仅取说明、源码和数据卡，没有批量下载这些厂家的训练数据。

## 实施前需要补的交付材料

1. 所选设备的完整配置、SDK/固件/机上系统版本和实际开放功能。
2. 原始回合样例、schema、每路时间、状态与命令定义、相机/工具标定。
3. 遥操作/记录器的程序化接口、保存完成依据、正常退出与失联行为。
4. 对应本体的仿真资产、控制器、传感器和目标任务场景。
5. 训练输出在设备端如何解释、以何频率运行、如何获得/释放控制权及回退。

这些缺项应变成工作台中的可见待办；不能因为文档目录中有某厂家名字，就显示该厂家已经接入。
