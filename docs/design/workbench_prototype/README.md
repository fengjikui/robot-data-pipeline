# 工作台方案原型

2026-10-26。双击 `index.html` 可离线打开，三个文件保持同一目录，无需安装依赖。全部使用相对路径，不联网、不连接设备、不调用训练或部署，不写正式工作区。刷新/重置恢复初始示例。

建议演示：总览（可展开自动串联，先演示因关键说明缺失而等待人工） → 采集会话（勾选保存失败并恢复）→ 数据资产（筛选与缺项）→ 准备训练数据（补说明、映射、读取，再切换配方）→ 训练与评估 → 部署条件/补采待办 → 运行记录。

采集、数据和模型状态全部是交互设计示例，不是 v0.1.2 已实现能力。真正的系统原生目录选择器仍在生产工作台；本原型不模拟系统弹窗。

详细方案见 `docs/product/11_交互逻辑与界面设计说明.md`。
