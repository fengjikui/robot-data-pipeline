# 数据采购两页内容稿

更新：2026 年 10 月 26 日。状态：可用于后续制作的两页文字稿，尚未生成 PPTX。对应前半部分新增第 6、7 页；完整需求与试用流程见 [采购验收说明](../product/09_任务驱动的数据选型与采购验收.md)。建议合计讲 2–3 分钟。

## 第 1 页 数据采购：甲方怎样提需求

### 页面内容

| 需求 | 甲方写清什么 |
| --- | --- |
| 任务与设备 | 要学哪些阶段；确切本体、手型、相机和控制范围 |
| 训练输入输出 | 所用配方；图像、状态、动作的含义与时间要求 |
| 覆盖与数量 | 场景/物体变化；不重复有效回合与时长、成功/失败分布 |
| 交付与责任 | 约定层级的数据包与版本、清单/schema、必要标定、转换产物与整改 |
| 使用条件 | 样本试用、训练/转换、存储环境及模型产物用途的约定 |

**已有数据：先拿清单与样本，对照缺口。委托采集：先试采，确认规格后分批交付。**

页面形式：主体为五行简表，下方一行说明两种采购路径。仅使用技术信息和简洁排版，避开模板页脚区域。

### 页脚来源与完整引用

页脚：Gebru 等，Datasheets for Datasets，2021，§3；Hugging Face Dataset Cards；本项目工程采购建议。

- [Datasheets for Datasets，v8](https://arxiv.org/abs/1803.09010v8)：数据组成、采集、缺失、用途与分发说明框架。
- [Dataset Cards](https://huggingface.co/docs/hub/datasets-cards)：来源说明和元数据组织。
- [本项目任务需求与采购验收](../product/09_任务驱动的数据选型与采购验收.md)：机器人专属字段、试采和验收建议。表中内容不是供应商统一标准，数值由具体项目确定。

### 配套演讲稿

我们先固定任务和目标本体，再讨论要采购什么。以搬箱为例，要说明需要抓取、抱持、负载移动和放置中的哪些阶段，同时把手型、相机、状态和动作的定义交代清楚。数量要结合不重复的有效回合、时长和场景覆盖来谈，数据量和原创示范量分开记录。已有数据先看清单和样本，确认缺口；如果需要新采，就先试采，修订并确认规格后再批量交付。双方还要明确交付哪些说明、转换由谁做、样本和数据允许怎样使用。这些内容形成一张可以逐项回答、逐项验收的需求单。

## 第 2 页 数据采购：用样本验证适配性

### 页面内容

1. **选样本**：从清单按任务/场景分层选取并加入随机样本，连同 schema、来源与已知缺项一起检查。
2. **跑流程**：预览与质量检查，验证字段/动作和时间，执行必要转换，再用目标训练器实际读取；按目标开展试训与独立任务评价。
3. **定范围**：直接满足、可按明确规则转换、需要额外材料/适配、需要补采或专项研究；分别记录责任和验证结果。

**读取通过、训练运行、任务效果分别记录；“简单转换”要有映射和可验证产物。**

页面形式：一条样本验证流程和四类判定结果。字段重排/已知单位换算与缺失动作/任务覆盖分别举一个短例子。

### 页脚来源与完整引用

页脚：LeRobotDataset v3；Unitree 官方转换器；本项目样本验证方案。

- [LeRobotDataset v3](https://huggingface.co/docs/lerobot/lerobot-dataset-v3)：特征、回合与训练读取组织。
- [Unitree 固定版转换器](https://github.com/unitreerobotics/unitree_lerobot/blob/41c2805742de879ddab2d8d6beaeaf215f876395/unitree_lerobot/utils/convert_unitree_json_to_lerobot.py)：特定字段与图像的打包范围，转换无法凭空产生缺失信号。
- [本项目采购验收说明](../product/09_任务驱动的数据选型与采购验收.md)：分层样本、试用流程与判定建议。效果阈值和样本规模需另外约定。

### 配套演讲稿

供应商说数据能用，或者做一下转换就能用，我们要把它变成可以复查的证据。先拿到清单与说明，选覆盖主要场景的样本，而不是只看几段成功视频。接着预览实际图像、状态和命令，检查时序，再按映射执行转换，用我们要用的训练器加载样本。如果只是已知单位换算或字段重排，可以做成重复执行的模板；如果缺少移动指令、关键相机或本体对应关系，就要补材料、补采或另做迁移研究。读取和小规模训练能证明接入程度，任务效果还要有足够试用数据和独立评价条件。最后根据这些结果确认采购范围，并对后续批次沿用约定的检查规则。
