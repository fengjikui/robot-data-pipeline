# 采集页分步放映

v18在新版前半部分的第2张幻灯片加入原生PPT动画，总张数仍为5张。原先预留的核心方案与实施内容仍待讨论，不因本次动画修改增加产品业务能力。

## 显示顺序

进入采集页时，先显示设备与网络拓扑。Wi-Fi/AP、Host与机器人之间的有线网络、交换网络分支和对应文字同时显示。

推进一次，拓扑线、AP图标及其文字隐藏，控制、图像、实际反馈和按配置的WebRTC显示路径与各自文字同时出现。设备本体、PC2/PC1分区、相机标注、程序、启动时间线和参考出处保持可见。

后退一次恢复拓扑。数据流显示完成后再推进一次，会正常进入下一张“数据处理、训练与部署”。

## 操作

请进入桌面PowerPoint或WPS的**放映模式**，编辑模式和静态预览通常会同时显示所有动画对象，不能用它们判断初始放映状态。

| 操作 | 作用 |
| --- | --- |
| 鼠标左键单击空白处 | 推进到数据流状态 |
| 向右 / 向下方向键，Page Down | 下一动画或下一页 |
| 向左 / 向上方向键，Page Up | 上一动画或上一页 |
| 滚轮向下 / 向上 | 本机Mac WPS实测可在两态间前进 / 后退，其他播放软件以实际行为为准 |

不要点击页面下方的参考链接来推进动画，那些文字仍会打开原始参考资料。

## 验证范围

2026-10-27已在本机Mac版WPS实际放映，检查了初始拓扑、右方向键推进、左方向键退回、滚轮下/上切换、鼠标单击以及动画结束后进入下一页。线条和标签同步切换，设备位置保持一致。Windows版PowerPoint/WPS尚未实际放映验证，报告前请在目标电脑试一次。

该文件使用PPT原生出现/消失动画，不需要宏、插件、外部脚本或互联网。原始资料的离线链接继续使用相对路径，换电脑时请完整解压资料包。
